# VEVA — Наша маленькая семья

Небольшая браузерная игра для Лены, Вовы, Лёши и Влады. Четыре независимые истории, без регистрации, сервера и сохранений.

## Запуск
Откройте index.html в браузере. Или запустите любой статический веб-сервер в этой папке. Зависимости и сборка не нужны.

## Публикация через GitHub Pages
Создайте публичный репозиторий и загрузите содержимое этой папки, включая скрытую папку .github. Основная ветка — main. В настройках репозитория откройте Pages и выберите источник GitHub Actions. После выполнения процесса «Публикация игры» GitHub покажет адрес сайта.

## Изменения после тестирования
Тексты, вопросы и варианты ответов находятся в game.js. Цвета и размеры — в style.css. Меню — assets/menu.png, сцены — assets/scenes.png. После изменений отправьте файлы в main: сайт обновится автоматически. Оригинальные фотографии в проект не включены, не загружайте их в репозиторий.

Музыка включается кнопкой «Звук». Управление мышью или касанием, в поездке также стрелками клавиатуры. Вкладку можно закрыть в любой момент — прогресс не сохраняется.
