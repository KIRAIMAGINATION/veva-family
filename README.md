# VEVA — Наша маленькая семья

Небольшая браузерная игра для Лены, Вовы, Лёши и Влады. Четыре независимые истории, без регистрации, сервера и сохранений.

## Запуск
Откройте index.html в браузере. Или запустите любой статический веб-сервер в этой папке. Зависимости и сборка не нужны.

## Публикация через GitHub Pages
В настройках репозитория откройте Pages, выберите «Deploy from a branch», ветку main и папку / (root), затем сохраните. GitHub автоматически опубликует сайт. Любые изменения в main обновляют игру.

## Изменения после тестирования
Тексты, вопросы и варианты ответов находятся в game.js. Цвета и размеры — в style.css. Меню — assets/menu-v2.png, сцены — assets/scenes.png, одежда и персонаж Влады — assets/wardrobe-v3.png, машина с Вовой — assets/vova-car-v2.png. После изменений отправьте файлы в main: сайт обновится автоматически. Оригинальные фотографии в проект не включены, не загружайте их в репозиторий.

Музыка включается кнопкой «Звук». Управление мышью или касанием, в поездке также стрелками клавиатуры. Вкладку можно закрыть в любой момент — прогресс не сохраняется.

## Обновление по семейному тестированию
В меню остались только имена. В гардеробной сменяются нарисованные спрайты нарядов, аксессуаров и обуви. Новый автомобиль с Вовой за рулём. В финале поездки — конфетти и «Дом, милый дом!». Анимация любви стала заметнее; все четыре истории заканчиваются победной мелодией, если звук включён.

Влада и весь гардероб заново нарисованы по девочке из правой нижней части утверждённой сцены. Первый наряд — розовая футболка и бежевая юбка, затем зелёный сарафан и голубое платье. Точки крепления аксессуаров и обуви подогнаны под новые пропорции.

Фон отражения гардеробной: assets/mirror-room.png. Он отрисовывается отдельным слоем за моделью и не влияет на крепления одежды, обуви или аксессуаров.
